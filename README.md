## О проекте / About

«Дом рекламы» работает как фонд и публичная платформа для поддержки новых форм рекламной деятельности и креативных коммуникаций.

Сейчас GitHub нужен проекту не как архив файлов, а как понятное рабочее пространство:

- для публичной витрины;
- для описания направлений и задач;
- для партнерских сценариев;
- для сбора материалов и предложений;
- для спокойной внутренней и внешней координации.

## Пять столпов / Five Pillars

| Направление | Что здесь собираем |
| --- | --- |
| Медиа | СМИ, издательские системы, кино, стриминг, media-tech и инфраструктура внимания |
| PR | Public relations, стратегические коммуникации, reputational systems и public response |
| Реклама | Агентства, холдинги, рекламные платформы, adtech, фестивали и отраслевые форматы |
| Дизайн | Design systems, визуальные платформы, UX/UI, product design, design-tech и премии |
| Диджитал | Разработчики, технологические компании, платформы, AI, agent systems, vibe coding и цифровая инфраструктура |

Подробная архитектура лежит здесь:
