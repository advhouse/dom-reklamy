# Дом рекламы / Advhouse

Фонд поддержки и продвижения новых форм рекламной деятельности «Дом рекламы» развивает инициативы на стыке рекламы, дизайна, медиа, PR, digital-коммуникаций, партнерств и современных креативных форматов.

Этот репозиторий задуман как публичный GitHub-hub проекта: здесь собираются описание фонда, структура работы, материалы для партнеров, тексты для витрины, GitHub-процессы и стартовые задачи.

## О проекте / About

«Дом рекламы» работает как фонд и публичная платформа для поддержки новых форм рекламной деятельности и креативных коммуникаций.

На текущем этапе GitHub нужен проекту не как архив файлов, а как понятный рабочий центр:

- для публичной витрины;
- для описания направлений и задач;
- для партнерских сценариев;
- для сбора материалов и предложений;
- для аккуратной командной и внешней координации.
