# Code of Conduct

Проект «Дом рекламы» стремится поддерживать уважительную, спокойную и рабочую среду для команды, партнеров, исполнителей и внешних участников.

## Expected behavior

- уважительное общение;
- конструктивная обратная связь;
- ясность формулировок;
- аккуратное обращение с непубличной информацией;
- уважение к времени и работе других участников.

## Unacceptable behavior

- оскорбления и давление;
- публикация секретов, токенов, ключей и приватных данных;
- неподтвержденные заявления от имени проекта;
- деструктивное поведение в обсуждениях и рабочих процессах.
