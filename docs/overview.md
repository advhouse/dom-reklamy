# Общее описание / Overview

«Дом рекламы» - проектный и организационный контур фонда, который занимается поддержкой и продвижением новых форм рекламной деятельности.

На практике это означает работу с такими направлениями, как:

- реклама;
- дизайн;
- медиа;
- PR;
- digital-коммуникации;
- партнерские и публичные форматы взаимодействия.

Этот GitHub нужен как понятный и аккуратный центр работы:

- чтобы объяснять проект;
- чтобы собирать витрину и структуру;
- чтобы координировать GitHub-процессы;
- чтобы давать людям и партнерам понятный вход;
- чтобы постепенно переводить проектные материалы в системный и прозрачный вид.

## Для кого

- для команды проекта;
- для партнеров;
- для внешних участников;
- для контентной и административной координации;
- для технической настройки GitHub и цифровой инфраструктуры.

## Что уже делается через GitHub

- выстраивается отдельный GitHub-контур проекта;
- настраиваются `SSH`, `API` и безопасный доступ через `1Password`;
- готовится витрина аккаунта и главного репозитория;
- собираются стартовые документы, шаблоны и точки входа.

## Что еще требует наполнения

- официальный публичный bio;
- карта основных репозиториев;
- стартовый набор открытых задач;
- партнерские шаблоны;
- публичные формулировки для внешних участников;
- витрина профиля и, при необходимости, отдельная GitHub Pages-страница.
