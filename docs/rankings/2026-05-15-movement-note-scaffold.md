## English

This scaffold is the shortest publication layer after a confirmed rerank trigger. Its purpose is speed with discipline. It is not meant to replace the full ranking package. It exists so the repository can publish a defensible movement update on the same day the trigger appears.

## Обязательные поля

- `date`
- `trigger company`
- `trigger type`
- `affected index`
- `movement`
- `why the movement is defensible`
- `next follow-up`

## Рабочий каркас

**Date:** `YYYY-MM-DD`

**Trigger company:** `Company`

**Trigger type:** `advertiser / workflow / deployment / commerce / creator / market execution`

**Affected index:** `index name`

**Movement:** `what moved and why`

**Why this is defensible:**  
`One short paragraph linking the trigger to the relevant threshold and matrix logic.`

**Next follow-up:**  
`Top 20 update / Top 5 update / watch continuation / scorecard refresh`

## Когда использовать

1. Trigger уже подтвержден.
2. Полный `Top 20` еще не собран.
3. Нужно быстро опубликовать дисциплинированное объяснение перестановки.

## Когда не использовать

1. Сигнал пока только `weak`.
2. Перестановка еще не защищена сравнительным тестом.
3. Нужен сразу полный рейтинг, а не короткая заметка.
