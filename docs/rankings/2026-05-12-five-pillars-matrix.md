# Дом рекламы: матрица выпуска по пяти столпам / 2026-05-12

![Weekly ranking preview](../../assets/editorial/previews/weekly-ranking-preview.svg)

Этот документ нужен для операционной сборки выпуска.

Он отвечает на три вопроса:

1. какая компания к какому столпу относится в первую очередь;
2. чем она уже покрыта в выпуске;
3. где у нас еще остаются пробелы.

## Как читать матрицу

Основной файл:

- [../../data/rankings/2026-05-12-five-pillars-matrix.csv](../../data/rankings/2026-05-12-five-pillars-matrix.csv)

Поля:

- `primary_pillar` — главный столп;
- `secondary_pillar` — вторичный столп, если он явно есть;
- `top20` — входит ли компания в основной недельный Top 20;
- `company_note` — есть ли отдельная заметка;
- `watchlist` — в каких watch-срезах компания уже фигурирует;
- `index_notes` — в каких индексных пояснениях она уже участвует;
- `top5_lists` — в каких коротких Top 5-срезах компания уже закреплена.

## Практический смысл

Эта матрица нужна, чтобы следующий запуск не выбирать интуитивно.

Теперь можно быстро видеть:

- кого уже разобрали достаточно глубоко;
- кого стоит добирать следующими заметками;
- какие столпы пока покрыты неровно;
- где есть избыточность, а где провал.

## Следующий полезный порядок

Если продолжать этот цикл дальше, логичный порядок такой:

1. усилить `OpenAI`, `HubSpot`, `VML`, `Netflix Ads`, `Spotify Advertising`;
2. отдельно добрать еще один короткий cross-pillar срез для агентско-медийного хвоста;
3. потом уже выравнивать столпы между собой;
4. затем переходить к следующему дню выпуска.
