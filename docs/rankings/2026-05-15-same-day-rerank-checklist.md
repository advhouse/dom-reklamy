## Checklist

- `Trigger confirmed`
- `Evidence threshold is sufficient or strong`
- `Rerank protocol conditions are satisfied`
- `Candidate order has been rechecked against the new signal`
- `Movement note is ready`
- `Rerank delta is ready`
- `Scorecards can be updated without ambiguity`
- `The move can be explained in one short defensible paragraph`

## Decision rule

- if every line above is true, publish the rerank package;
- if one or more lines fail, do not publish the rerank yet;
- if only the threshold fails, remain in watch mode;
- if only the explanation fails, fix the note before publishing.
