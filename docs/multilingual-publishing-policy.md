# Multilingual Publishing Policy

`Дом рекламы / Advhouse` ведет публичный editorial и ranking layer как многоязычный контур.

## Базовое правило

Все публичные статьи, заметки, эссе, weekly rankings, index notes и методологические публикации должны выходить на шести официальных языках ООН:

- Arabic
- Chinese
- English
- French
- Russian
- Spanish

## Что считается обязательной многоязычной публикацией

- editorial notes
- essays
- weekly rankings
- methodology updates
- ranking explanations
- public statements

## Рабочее правило

Внутренний черновик может быть сделан на одном языке.

Публичная публикация считается завершенной только тогда, когда в ней есть все шесть языковых блоков.

## Предпочтительный формат

Для GitHub предпочтителен единый файл, внутри которого собраны все шесть языковых версий одного текста.

Это упрощает:

- публикацию;
- версионность;
- ссылки;
- публичные обсуждения;
- сравнение редакций.
