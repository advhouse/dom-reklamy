# GitHub Organization Profile Pack

Этот файл нужен, если позже для «Дом рекламы» будет создана отдельная GitHub Organization.

## Когда переходить на Organization

- когда у проекта появится несколько репозиториев;
- когда понадобится развести роли и доступы;
- когда профиль должен выглядеть институционально, а не как личный аккаунт.

## Что должно быть у Organization

- понятное имя;
- короткий bio;
- website;
- social links;
- pinned repositories;
- organization profile README.

## Минимальная логика pinned repositories

1. Главный репозиторий
2. Website or GitHub Pages
3. Materials or public docs
4. Infrastructure or integrations repo, если появится
