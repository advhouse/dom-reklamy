# Бренд и тон / Brand & Voice

## Название

Рабочее публичное название проекта:

**Дом рекламы**

Официальная длинная форма, зафиксированная в рабочих данных:

**Фонд поддержки и продвижения новых форм рекламной деятельности "Дом рекламы"**

## Тон

Коммуникация проекта должна быть:

- ясной;
- собранной;
- современной;
- профессиональной;
- без канцелярского шума;
- без пустой саморекламы.

Подробный документ по голосу проекта лежит здесь:

- [voice-style.md](./voice-style.md)

## Что важно в тоне

- говорить по делу;
- не распадаться на слишком разные стили в разных местах;
- не обещать неподтвержденные партнерства;
- не писать так, будто проект уже оформлен сильнее, чем это есть на практике;
- сохранять уверенный и аккуратный публичный голос;
- не копировать язык агентских презентаций и корпоративных отчетов;
- держать единый стиль речи в README, статьях, рейтингах и партнерских текстах.

## В GitHub это означает

- короткие и понятные описания;
- ясные README и шаблоны обращений;
- минимизацию случайных черновиков;
- аккуратный внешний вид профиля и репозиториев.
