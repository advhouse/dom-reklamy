# Карта внешнего круга GitHub

Этот документ нужен, чтобы `Дом рекламы` видел не только отдельные компании, а всю внешнюю среду целиком.

Дата рабочей фиксации этой версии: `12 мая 2026 года`.

## Зачем это нужно

`Дом рекламы` не должен замыкаться только на собственных рейтингах и собственных текстах.

Нам нужен внешний круг:

- кого наблюдать;
- где идет движение;
- где появляются новые инструменты;
- где обсуждаются формы рекламы, дизайна, медиа, PR и digital;
- где формируется среда AI и будущих агентных систем.

## Направления

Внешний круг сейчас собирается по восьми направлениям:

1. `Реклама`
2. `Медиа`
3. `PR`
4. `Дизайн`
5. `Digital`
6. `Разработчики`
7. `AI`
8. `AGI / ASI горизонт`

## 8. AGI / ASI горизонт

Здесь важно быть точным.

`AGI` и тем более `ASI` пока нельзя превращать в красивую вывеску без опоры на реальные рабочие узлы.

### Что можно делать честно

- следить за frontier AI-компаниями;
- следить за агентными фреймворками;
- смотреть, где появляются признаки более автономных систем;
- смотреть, как меняется слой AI-инструментов для творчества, коммуникаций и управления.

### Что нельзя утверждать сейчас

- что существует зрелый отдельный `ASI GitHub market`;
- что у нас уже есть надежный перечень компаний “ASI-направления”;
- что любой громкий AI-бренд автоматически относится к AGI или ASI.

### Практический вывод

Для работы `Дом рекламы` слой `AGI / ASI` пока ведется как `горизонт наблюдения`, а не как самостоятельная операционная корзина подписок.

## Как двигаться

Правильный порядок наблюдения:

1. `Дизайн`
2. `PR`
3. `Digital`
4. `Реклама`
5. `Медиа`
6. `Разработчики`
7. `AI`
8. `AGI / ASI горизонт`

## Что делать между рейтингами

- смотреть новые репозитории и продуктовые релизы;
- смотреть, кто становится заметнее;
- пополнять внешнюю карту;
- выпускать короткие заметки по компаниям;
- усиливать входы в Discussions и Issues;
- готовить спокойные приглашения к открытому участию.
