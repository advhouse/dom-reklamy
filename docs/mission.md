# Миссия / Mission

Миссия GitHub-контура «Дом рекламы» - сделать проект понятным, рабочим и доступным для координации, партнерств и публичного представления.

Здесь важны не только файлы, но и сама логика работы:

- одна понятная витрина;
- один главный репозиторий;
- аккуратный вход для партнеров и участников;
- безопасная работа с доступами;
- понятная карта того, что проект делает и как в него включаться.

## Принципы

- не создавать хаос из разрозненных папок и черновиков;
- не смешивать доступы разных аккаунтов;
- не публиковать секреты и приватные данные;
- не обещать больше, чем реально подтверждено;
- делать GitHub удобным и для команды, и для внешнего человека.
