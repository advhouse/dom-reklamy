# Шаблон еженедельной рейтинговой публикации

Ниже базовый шаблон для еженедельной публикации рейтинга в GitHub.

## Header

`Дом рекламы / Advhouse: рейтинг недели`

`Week of YYYY-MM-DD`

## Language Rule

Каждая еженедельная рейтинговая публикация должна содержать шесть языковых блоков:

- Arabic
- Chinese
- English
- French
- Russian
- Spanish

Политика зафиксирована здесь:

- [multilingual-publishing-policy.md](./multilingual-publishing-policy.md)

Если у еженедельной рейтинговой публикации есть обложка или превью:

- общее превью для шестиязычного файла должно быть без текста;
- текстовые версии изображения допускаются только как отдельные локализованные варианты для каждого языка.

## Method Note

Рейтинг основан на публичной индексной модели `Дом рекламы / Advhouse`, которая учитывает:

- Индекс креативной силы
- Индекс рыночного влияния
- Индекс репутации и доверия
- Индекс технологической зрелости
- Индекс дистрибуции и платформенной силы
- Индекс фестивального присутствия
- Индекс публичной открытости
- Индекс недельной динамики

## Пересмотр рейтинга

Если компания считает, что в рейтинге есть фактическая ошибка, она может подать запрос на пересмотр через GitHub issue template.
