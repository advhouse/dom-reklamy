# Партнеры / Partners

GitHub для `Дом рекламы` должен быть не только внутренним рабочим местом, но и понятной точкой входа для партнеров.

## Что партнер должен понять сразу

- кто вы;
- чем занимается проект;
- куда писать или что открывать;
- как можно поддержать проект;
- где видны совместные действия и участие.

## Формы участия

- предложить сотрудничество;
- прислать материал или ссылку;
- предложить мероприятие или совместную активность;
- помочь с текстами, витриной, структурой или контентом;
- поддержать проект публичным упоминанием или репозиторной интеграцией.

## Что должен дать GitHub

- понятный `README`;
- шаблон обращения под партнерский запрос;
- discussions для открытого общения;
- контактные точки;
- аккуратную структуру без лишнего шума.

## Как должен звучать партнерский текст

Партнерский текст должен быть:

- уважительным;
- ясным;
- спокойным;
- без давления;
- без искусственной важности;
- без пустых обещаний.

Партнер должен быстро понимать, что здесь есть структура, внимание к деталям и нормальный человеческий тон.
