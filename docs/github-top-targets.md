# GitHub Top Targets

Этот документ фиксирует первую сильную волну GitHub-целей для `Дом рекламы / Advhouse` вокруг мирового рекламного, креативного, медийного и digital-контура.

Цель не в том, чтобы хаотично подписаться на сотни случайных аккаунтов, а в том, чтобы собрать рабочий внешний круг влияния:

- платформы и компании из контура `Cannes Lions`;
- компании, связанные с креативом, медиа, дизайном и digital;
- технические и продуктовые репозитории, которые реально формируют современную среду коммуникаций.

Важно: у большинства крупных рекламных премий GitHub не является их основной публичной площадкой. Поэтому основной вес здесь переносится на компании, платформы, партнеров, спикеров и технологические организации вокруг этих премий.

## Приоритеты

- `Follow account`: следить за организацией или компанией как за публичным GitHub-узлом.
- `Star repo`: сохранить конкретный сильный репозиторий как ориентир, инструмент или сигнал внимания.

- `Cannes Lions`
- `D&AD Awards`
- `Clio Awards`
- `The One Show`
- `Effie Awards`
- `ADC Annual Awards`
- `London International Awards`
- `Epica Awards`
- `Eurobest`

Но GitHub-ядро собирается не вокруг самих award-брендов, а вокруг:

- партнеров фестивалей;
- спикеров и жюри;
- технологических платформ;
- агентств и продуктовых компаний;
- дизайн- и digital-систем.
