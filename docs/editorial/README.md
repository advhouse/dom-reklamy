# Editorial Layer

Это первая редакционная волна `Дом рекламы / Advhouse`.

Здесь собраны короткие публичные заметки по ключевым направлениям проекта. Их задача не в том, чтобы исчерпывающе объяснить рынок, а в том, чтобы показать голос, фокус и интеллектуальную рамку проекта.

- как стартовую публичную витрину мысли;
- как основу для будущих эссе и weekly commentary;
- как редакционный материал для GitHub, сайта и партнерских разговоров;
- как первый уровень интеллектуальной дисциплины вокруг проекта.
