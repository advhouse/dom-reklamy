# Редакционный раздел

Это первая подборка редакционных текстов `Дом рекламы / Advhouse`.

Здесь собраны короткие публичные заметки по ключевым направлениям проекта. Их задача не в том, чтобы исчерпывающе объяснить рынок, а в том, чтобы показать голос, фокус и интеллектуальную рамку проекта.

Каждая заметка может и должна открываться маленьким тематическим превью. Это делает публикации на GitHub визуально живее, помогает навигации и постепенно формирует узнаваемый редакционный стиль проекта.

Если заметка собрана в одном файле сразу на шести языках, общее превью в начале файла должно быть без текстовых надписей. Текст внутри изображения допускается только в локализованной версии, привязанной к конкретному языковому блоку.

Все тексты в этом слое публикуются на шести официальных языках ООН:

- Arabic
- Chinese
- English
- French
- Russian
- Spanish

Общее правило зафиксировано здесь:

- [multilingual-publishing-policy.md](../multilingual-publishing-policy.md)
- [voice-style.md](../voice-style.md)
