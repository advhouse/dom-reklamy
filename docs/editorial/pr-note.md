# PR начинается там, где заканчивается самореклама

PR часто ошибочно сводят к видимости. Но видимость без доверия быстро превращается в шум, а доверие без последовательности не удерживается. Настоящий PR работает не только с охватом, но и с качеством общественного отношения.

Сегодня сильный PR строится вокруг трех вещей: репутации, объяснимости и устойчивости. Репутация отвечает за долгую память о бренде, объяснимость помогает людям быстро понять, кто вы и зачем вы нужны, а устойчивость показывает, выдерживает ли ваша позиция давление событий.

Поэтому PR будущего не может быть только службой реагирования. Он должен быть архитектурой публичной ясности. Он должен соединять слова, действия, партнерства, лидерские сигналы и доказуемую реальность проекта.

Для `Дом рекламы` это означает, что каждое публичное сообщение должно проверяться простым вопросом: усиливает ли оно доверие к системе, или просто добавляет очередную единицу контента в переполненное пространство.
