# Пять столпов `Дом рекламы`

Этот документ фиксирует базовую архитектуру проекта.

Для `Дом рекламы` внешний мир, GitHub-карта, публикации, рейтинги, партнерства и наблюдение за средой собираются вокруг пяти столпов.

## 1. Медиа

Сюда входит весь мировой медийный контур:

- бумажные носители;
- электронные носители;
- цифровые носители;
- телевидение;
- киноиндустрия;
- стриминговые платформы;
- издательские системы;
- media-tech;
- инфраструктура внимания и дистрибуции.

## 2. PR

Сюда входит весь контур public relations:

- PR-агентства;
- стратегические коммуникации;
- reputational systems;
- public response systems;
- community relations;
- технологии PR;
- профессиональные институции и специалисты;
- инструменты управления доверием и публичной позицией.

## 3. Реклама

Сюда входит весь мировой рекламный контур:

- агентства;
- рекламные холдинги;
- креативные сети;
- adtech;
- advertising platforms;
- фестивали;
- выставки;
- конференции;
- семинары;
- журналы;
- алгоритмы и цифровые рекламные системы.

## 4. Дизайн

Сюда входит весь дизайн-контур:

- design companies;
- visual platforms;
- design systems;
- художники и студии;
- UX/UI;
- product design;
- creative tooling;
- design-tech;
- AI-инструменты для визуальной работы;
- премии и институции дизайна.

## 5. Диджитал

Сюда входит весь технологический и цифровой контур:

- разработчики;
- технологические компании;
- платформы;
- software ecosystems;
- cloud and infrastructure;
- AI;
- agent systems;
- frontier tech;
- vibe coding;
- все, что формирует современную рабочую цифровую среду.

Важно:

- `разработчики` входят в пятый столп `диджитал`;
- `AI` входит в пятый столп `диджитал`;
- `AGI / ASI` пока ведется как горизонт наблюдения внутри пятого столпа, а не как отдельный столп.

## Практический вывод

Все, что мы делаем в репозитории, должно сначала соотноситься с одним из пяти столпов.

После этого уже можно:

- включать компанию в карту;
- добавлять репозиторий в наблюдение;
- публиковать заметку;
- ранжировать индексами;
- строить партнерский и публичный контур.
