# Шаблоны команды

Эта папка содержит рабочие шаблоны для внутренних и публичных материалов проекта.

## Файлы

- `employee-profile-template.md` - карточка одного сотрудника.
- `employee-register.csv` - реестр сотрудников и ролей.
- `chat-register.csv` - реестр рабочих чатов.
- `team-renaming-checklist.md` - чеклист внедрения порядка в контактах, чатах и аватарках.
- `github-profile-readme.md` - универсальный шаблон GitHub profile README.
- `github-profile-readme-personal.md` - вариант для личного GitHub-профиля.
- `github-profile-readme-organization.md` - вариант для GitHub Organization.
- `article-template.md` - короткая или средняя статья.
- `essay-template.md` - авторское эссе.
- `research-note-template.md` - исследовательская заметка.
- `weekly-ranking-post-template.md` - публикация недельного рейтинга.
- `public-response-template.md` - публичный ответ партнеру, участнику или компании.

Главный стандарт описан в [../docs/team-identity-system.md](../docs/team-identity-system.md).
Стиль речи проекта описан в [../docs/voice-style.md](../docs/voice-style.md).

## Базовый формат

```text
[PROJECT] | [ROLE] | [ИМЯ ОТЧЕСТВО ФАМИЛИЯ]
```

Для текущего бренда можно использовать рабочий код `OCEAN`, если команда утвердит его как единый код проекта.
