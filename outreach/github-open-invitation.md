# Открытое приглашение к участию

Этот текст нужен как основа для публичного приглашения в GitHub, Discussions, README и партнерских сообщениях.

## Короткая версия

`Дом рекламы` развивает открытое пространство на стыке рекламы, дизайна, медиа, PR, digital, разработки и AI.

Если вам близки эти темы, можно подключаться через идеи, материалы, наблюдения, ссылки, исследования, обсуждения и совместные инициативы.

## Рабочая версия

`Дом рекламы` собирает открытое рабочее пространство для новых форм рекламной деятельности и креативных коммуникаций.

Нас интересуют:

- реклама;
- дизайн;
- медиа;
- PR;
- digital;
- разработка;
- AI и агентные системы;
- публичные рейтинги и индексные модели.

Если вы:

- ведете сильный репозиторий;
- делаете полезный инструмент;
- публикуете исследование;
- развиваете design system;
- работаете с media-tech, adtech, martech или AI;
- хотите предложить сотрудничество или обсуждение,

можно входить через Issues, Discussions и публичные материалы репозитория.

## Тон приглашения

- спокойно;
- уважительно;
- без давления;
- без ложной важности;
- без обещаний, которые мы не можем подтвердить.
