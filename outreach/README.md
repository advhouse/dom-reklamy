# Коммуникации и партнерства / Outreach

Раздел `outreach/` помогает вести аккуратную внешнюю коммуникацию: письма партнерам, заявки на события, звонки и список целевых организаций.

## Правила

- Не отправлять письма от имени конкретного человека без согласования.
- Не обещать партнерство, финансирование или программу до подтверждения.
- Указывать ранний статус проекта честно.
- Для публичных материалов использовать только утвержденные контакты.
- Фиксировать follow-up в GitHub Issue `partner-lead`, если это можно делать публично.
- Держать единый голос проекта по [docs/voice-style.md](../docs/voice-style.md).
