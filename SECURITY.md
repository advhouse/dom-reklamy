# Security

## Reporting

Не публикуйте детали уязвимостей, токены, ключи и чувствительные данные в открытых `Issues`, `Pull Requests` или `Discussions`.

## Do not commit

- API keys
- access tokens
- private SSH keys
- real `.env` files
- personal data without clear need
- private partner materials

## Before pushing

- check that no secret files were added;
- check that no private keys were committed;
- check that public wording does not expose internal-only information.
